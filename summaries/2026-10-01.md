# 🐟 GoFish Weekly Update (2026-09-24 → 2026-10-01)

## Highlights
This week focused on making charts cheaper to run and easier to clean up: `render()` now returns a View you can unmount, sliders and timers do less work, and the performance benchmark hang is fixed. Animation work (build-in transitions, trails, smooth curves) and a cleaner `relate()` API also landed, along with the first steps toward shape geometry and circle packing.

## What changed
**Performance and lifecycle**
- [PR #959](https://github.com/gofish-graphics/gofish-graphics/pull/959) fixes the Performance Benchmark hang by disposing charts and budgeting renders.
- [PR #963](https://github.com/gofish-graphics/gofish-graphics/pull/963): `render()` returns a View with `unmount()`, and a `timer()` only ticks while something reads it.
- [PR #964](https://github.com/gofish-graphics/gofish-graphics/pull/964): the slider's handle, readout and fill update at paint time, so reading its value no longer re-runs layout for the whole chart.

**Animation**
- [PR #901](https://github.com/gofish-graphics/gofish-graphics/pull/901) prototypes build-in animation with `time.stagger`, `animation.*` and `.transition()`.
- [PR #902](https://github.com/gofish-graphics/gofish-graphics/pull/902) ports the animated connected scatterplot, adds trails, data-parameterized curves, and a monotone cubic default.
- [PR #892](https://github.com/gofish-graphics/gofish-graphics/pull/892): bar chart race labels tween with their marks, and enter/exit fade by default.

**API improvements**
- [PR #968](https://github.com/gofish-graphics/gofish-graphics/pull/968) adds node `geometry()` with `enclosingCircle`, plus a `pack` operator. [PR #966](https://github.com/gofish-graphics/gofish-graphics/pull/966) is the design note behind it.
- [PR #930](https://github.com/gofish-graphics/gofish-graphics/pull/930): `.constrain()` is now `.relate()`, and its clauses can draw and are ordered by dependency.
- [PR #923](https://github.com/gofish-graphics/gofish-graphics/pull/923): string names resolve by the closest match, bounded by `createMark`.
- [PR #940](https://github.com/gofish-graphics/gofish-graphics/pull/940) coordinates axis names through dims and adds a coord-named `dir`.
- [PR #922](https://github.com/gofish-graphics/gofish-graphics/pull/922) retires the v1/v2/v3 API naming.

**Bug fixes**
- [PR #965](https://github.com/gofish-graphics/gofish-graphics/pull/965): `polygon` fills given as a field name now go through the color scale instead of rendering black.
- [PR #931](https://github.com/gofish-graphics/gofish-graphics/pull/931): a batch of small fixes, including the circle default color and Python keyword options.

**Docs and tooling**
- [PR #915](https://github.com/gofish-graphics/gofish-graphics/pull/915) builds the planets diagram across the Basics and Diagrams tutorials.
- [PR #911](https://github.com/gofish-graphics/gofish-graphics/pull/911) fixes the ribbon grouping in the Charts tutorial.
- [PR #912](https://github.com/gofish-graphics/gofish-graphics/pull/912): tutorial previews are now build-time images.
- [PR #951](https://github.com/gofish-graphics/gofish-graphics/pull/951) and [PR #900](https://github.com/gofish-graphics/gofish-graphics/pull/900) make visual review baseline acceptance and reruns more reliable.
- [PR #924](https://github.com/gofish-graphics/gofish-graphics/pull/924) tweaks how the weekly summary credits contributors.
