# 🐟 GoFish Weekly Update (2026-10-15 → 2026-10-22)

## Highlights

This week was mostly about Python parity: many more stories now render byte-identically from Python and JS, and charts compose recursively across the bridge. On the JS side, `enclose` was reworked into one flexible mark with several outline shapes, and connectors got a layout fix.

## What changed

**Enclose and connectors**

- `enclose` is now a single relational mark that outlines a set of nodes with `Shape.box()`, `Shape.oval()`, `Shape.blob()`, `Shape.hull()` or `Shape.spine()`. `background` is gone. ([PR #1152](https://github.com/gofish-graphics/gofish-graphics/pull/1152))

![Penguins outlined with box, hull, blob and spine](https://raw.githubusercontent.com/gofish-graphics/gofish-graphics/pr-assets/pr-1152/impl2-penguins-four-shapes.png)

- Connectors now count their routed path (arcs, arrows, smooth curves) in the bounding box, so they no longer get clipped. ([PR #1172](https://github.com/gofish-graphics/gofish-graphics/pull/1172))

![Arc tree after the connector fix](https://raw.githubusercontent.com/gofish-graphics/gofish-graphics/pr-assets/pr-1172/arc-tree-after.png)

**Python parity**

- Step 7 adds callable marks, refs in rows, `z_order` callbacks and separate angle conventions for polar and clock, plus 15 more ported stories. ([PR #1189](https://github.com/gofish-graphics/gofish-graphics/pull/1189))
- The previously exempt stories are ported, charts compose recursively across the Python↔JS bridge, and there is a new review rule for Python code. ([PR #1177](https://github.com/gofish-graphics/gofish-graphics/pull/1177))

![Position showcase rendered from Python](https://raw.githubusercontent.com/gofish-graphics/gofish-graphics/pr-assets/pr-1177/position-showcase.png)

- `gofish.gotree` brings the tree grammar to Python, with 40 ported gallery stories that match their JS DOM. ([PR #811](https://github.com/gofish-graphics/gofish-graphics/pull/811))
- A generated `Coord` family (including `geo`) lands in Python. The broken `bipolar`, `arcLengthPolar` and `linear` transforms are removed. ([PR #1157](https://github.com/gofish-graphics/gofish-graphics/pull/1157))
- The Nested Mosaic Chart story is ported via the lambda bridge. ([PR #807](https://github.com/gofish-graphics/gofish-graphics/pull/807))
