# 🐟 GoFish Weekly Update (2026-11-12 → 2026-11-19)

## Highlights

A quiet week focused on API tidiness and docs quality. `spread`'s `anchor` option was replaced by a new `Spacing` strategy family, and the docs gallery now checks that its examples only use public names.

## What changed

- **API improvements**
  - `spread`'s `anchor` option is gone. How the distance between neighbors is measured is now the value of `spacing`, through the new `Spacing` family, starting with `Spacing.pitch` ([PR #1365](https://github.com/gofish-graphics/gofish-graphics/pull/1365)). This is the first piece of the optical spacing proposal. The optical strategies and `Spacing.contour` come later.
- **Documentation**
  - `check-story-examples` now compares gallery stories against the public exports of `src/lib.ts`. Five stories had been publishing names that aren't exported (`clock` and the box-and-whisker helpers), and those are now caught ([PR #1359](https://github.com/gofish-graphics/gofish-graphics/pull/1359)).
