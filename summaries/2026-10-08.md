# 🐟 GoFish Weekly Update (2026-10-01 → 2026-10-08)

## Highlights
This week focused on layout correctness and cleanup. Y direction and chart chrome moved into the layout pipeline, signed bars and paint order got fixes, and the Python bridge was tidied up. Scatter charts also gained new ways to handle overlapping points.

## What changed
**Layout and rendering**
- Y direction now lives on each node's axis, and axis titles, legends and colorbars are built by the node they describe ([PR #1040](https://github.com/gofish-graphics/gofish-graphics/pull/1040)).
- Signed `h`/`w` values now grow from the axis's 0 ([PR #985](https://github.com/gofish-graphics/gofish-graphics/pull/985)). Signed stacks lay parts end to end ([PR #993](https://github.com/gofish-graphics/gofish-graphics/pull/993)).
- Space types are now separate from size claims, and the SIZE and POSITION code paths are merged ([PR #1015](https://github.com/gofish-graphics/gofish-graphics/pull/1015)).
- Each layer now sorts only its own children for paint order ([PR #988](https://github.com/gofish-graphics/gofish-graphics/pull/988)).
- The `position()` offset is now counted once ([PR #1055](https://github.com/gofish-graphics/gofish-graphics/pull/1055)).
- `labelAngle: "auto"` picks an angle for each row of axis labels ([PR #961](https://github.com/gofish-graphics/gofish-graphics/pull/961)).

**New features and API changes**
- `scatter` has a new `overlap` option with `separate()` and `jitter()` strategies, and the IR can now carry ±Infinity ([PR #1003](https://github.com/gofish-graphics/gofish-graphics/pull/1003)). `jitter` was then renamed `noise()` with a Gaussian outline, plus `sina()` and `jitter()` wrappers ([PR #1018](https://github.com/gofish-graphics/gofish-graphics/pull/1018)).
- `treemap` tile strategies are now objects, matching `pack`. It gains spacing and padding, and `flipY` is gone ([PR #1005](https://github.com/gofish-graphics/gofish-graphics/pull/1005)).
- `line` and `ribbon` accept `step`, and a new `smooth` curve completes the step, linear, monotone, smooth ladder ([PR #960](https://github.com/gofish-graphics/gofish-graphics/pull/960)).
- The Python API is now consistently snake_case ([PR #1008](https://github.com/gofish-graphics/gofish-graphics/pull/1008)).

**Fixes**
- A re-render scheduled before `dispose()` no longer calls an undefined function ([PR #981](https://github.com/gofish-graphics/gofish-graphics/pull/981)).
- Two aggregate bar chart stories now read top-down like their Vega-Lite originals ([PR #1031](https://github.com/gofish-graphics/gofish-graphics/pull/1031)).

**Cleanup and tooling**
- Serialization now comes from the descriptor table ([PR #1071](https://github.com/gofish-graphics/gofish-graphics/pull/1071)). The widget and parity harness share one IR deserializer ([PR #1042](https://github.com/gofish-graphics/gofish-graphics/pull/1042)).
- Unused d3 packages are removed, and culori replaces chroma-js ([PR #1061](https://github.com/gofish-graphics/gofish-graphics/pull/1061)).
- The outdated in-package Python story suite is deleted ([PR #1048](https://github.com/gofish-graphics/gofish-graphics/pull/1048)).
- `AGENTS.md` is now a symlink to `CLAUDE.md` ([PR #1043](https://github.com/gofish-graphics/gofish-graphics/pull/1043)).
- Visual review statuses link the run's own deployment ([PR #1041](https://github.com/gofish-graphics/gofish-graphics/pull/1041)), and the weekly summary suppresses Discord link previews ([PR #1027](https://github.com/gofish-graphics/gofish-graphics/pull/1027)).

**Docs**
- New design note on distributions as first-class datatypes ([PR #983](https://github.com/gofish-graphics/gofish-graphics/pull/983)).
