# 🐟 GoFish Weekly Update (2026-09-17 → 2026-09-24)

## Highlights
10 PRs landed this week 🎉, headlined by new animation support (`time.sequence`/`time.transition`) and a `geo()` coordinate transform that powers a full replication of the *Animated Vega-Lite* bird migration figure. Docs got a structural overhaul (tutorials index, generated vs. handwritten tiers), visual-test CI got faster, and the weekly summarizer itself got fixed up to run on Discord and the Claude subscription instead of API credits.

## What changed
**Animation & visualization examples**
- Gapminder scatter now animates with `time.sequence` and `time.transition` ([PR #886](https://github.com/gofish-graphics/gofish-graphics/pull/886))
- Finished panels B-E of the Animated Vega-Lite bird migration replication ([PR #866](https://github.com/gofish-graphics/gofish-graphics/pull/866))
- Added a `geo()` coordinate transform, framed coordinate spaces, and coord hoisting to support it ([PR #865](https://github.com/gofish-graphics/gofish-graphics/pull/865))

**Docs**
- New tutorials index branching into Basics, Charts, and Diagrams ([PR #869](https://github.com/gofish-graphics/gofish-graphics/pull/869))
- Docs split into a generated reference tier and a flagged handwritten tier ([PR #862](https://github.com/gofish-graphics/gofish-graphics/pull/862))

**CI & infra**
- Sped up visual-test CI via split capture, parallel parity, and concurrent capture ([PR #882](https://github.com/gofish-graphics/gofish-graphics/pull/882))
- Weekly summarizer now runs on the Claude subscription instead of billed API credits ([PR #884](https://github.com/gofish-graphics/gofish-graphics/pull/884))
- Dropped an explicit model flag that was breaking the summarizer step ([PR #885](https://github.com/gofish-graphics/gofish-graphics/pull/885))
- Weekly PR summary now posts to Discord instead of Slack ([PR #883](https://github.com/gofish-graphics/gofish-graphics/pull/883))

**Core**
- Simplified the AST backbone and stripped stale comments, ~680 lines removed ([PR #839](https://github.com/gofish-graphics/gofish-graphics/pull/839))
