# 🐟 GoFish Weekly Update (2026-10-08 → 2026-10-15)

## Highlights
This week the library got a big axes overhaul (axes are now on by default) and a time datatype that reaches all the way to calendar bins and heatmaps. Units and axis titles also got smarter, and the contributor workflow got some tooling polish.

## What changed
**Axes and units**
- Axes are on by default for `chart()`. Domains are keyed by measure and shared by constraints, and continuous axes are drawn only at chart boundaries ([PR #1129](https://github.com/gofish-graphics/gofish-graphics/pull/1129)).
![Faceted scatter with shared axes](https://raw.githubusercontent.com/gofish-graphics/gofish-graphics/pr-assets/pr-1129/faceted-chart--faceted-scatter-driving-after.png)
- Bare column names are now unknown units that unify, so columns like `lo`/`hi` share an axis without extra tagging ([PR #1125](https://github.com/gofish-graphics/gofish-graphics/pull/1125)).
- Default axis titles come from a column's quantity and unit, like `Production Budget (USD)` ([PR #1126](https://github.com/gofish-graphics/gofish-graphics/pull/1126)).
![Box plot with unit-aware axis title](https://raw.githubusercontent.com/gofish-graphics/gofish-graphics/pr-assets/pr-1127/box-plot-pay-usd.png)
- A column's unit now lives in the column-type record ([PR #1118](https://github.com/gofish-graphics/gofish-graphics/pull/1118)).

**Time and partitions**
- Cells, partitions, calendar bins and axis levels landed together ([PR #1133](https://github.com/gofish-graphics/gofish-graphics/pull/1133)), building on the calendar time axis from [PR #1066](https://github.com/gofish-graphics/gofish-graphics/pull/1066).
![Calendar heatmap](https://raw.githubusercontent.com/gofish-graphics/gofish-graphics/pr-assets/pr-1133/bin--calendar-heatmap-v2.png)

**API internals**
- A split with no `by` is now a split by row identity, so every leaf is a list ([PR #1127](https://github.com/gofish-graphics/gofish-graphics/pull/1127)).
- Each strategy family has one namespace, and strategies share one wire shape ([PR #1094](https://github.com/gofish-graphics/gofish-graphics/pull/1094), [PR #1096](https://github.com/gofish-graphics/gofish-graphics/pull/1096)).
- Python parity step 3 adds compose, pluck, filter, circle, lambda channels and option checks ([PR #1093](https://github.com/gofish-graphics/gofish-graphics/pull/1093)).
- The Flower Chart moved to the fluent API ([PR #1113](https://github.com/gofish-graphics/gofish-graphics/pull/1113)).

**Docs and tooling**
- New internals essay on how axes work ([PR #1117](https://github.com/gofish-graphics/gofish-graphics/pull/1117)), plus an api-proposal skill and API design rules ([PR #1139](https://github.com/gofish-graphics/gofish-graphics/pull/1139)).
- The Visual Diff Review site now shows each story's spec ([PR #1146](https://github.com/gofish-graphics/gofish-graphics/pull/1146)), and the weekly summary can include screenshots ([PR #1154](https://github.com/gofish-graphics/gofish-graphics/pull/1154)).
- PR guidelines now prefer fewer, larger PRs and ask for before/after API examples ([PR #1143](https://github.com/gofish-graphics/gofish-graphics/pull/1143), [PR #1140](https://github.com/gofish-graphics/gofish-graphics/pull/1140)).
- CI moved to Node 26 ([PR #1077](https://github.com/gofish-graphics/gofish-graphics/pull/1077)) and visual tests got faster through sharding ([PR #1067](https://github.com/gofish-graphics/gofish-graphics/pull/1067)).
