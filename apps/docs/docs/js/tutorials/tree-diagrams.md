::: tip Before you start
This page assumes [Basics](/js/tutorials/basics) for marks, operators and
`layer()`. Trees are drawn with the companion `gofish-gotree` package, which
you install alongside GoFish.
:::

Hierarchies are their own kind of data, and a tree layout is its own kind of
flow. This tutorial will take one hierarchy and draw it four ways, as a
node-link diagram, a treemap, a sunburst, and an indented list, changing only
how the tree is laid out and what each node is drawn as. The marks are the ones
you already know, so the new part is the tree itself.
