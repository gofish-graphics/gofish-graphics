This is a short book about how GoFish works inside. Each chapter answers one question, and each is written from the code as it is today. When the code a chapter reads changes, the chapter says so at the top, and it is rebuilt from the code rather than patched.

If a part loses you, bores you or looks wrong, give feedback. Every paragraph has a feedback button, and feedback goes into the plan for the chapter's next rebuild.
