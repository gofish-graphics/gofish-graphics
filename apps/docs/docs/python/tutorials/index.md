# Tutorials

::: warning Coming soon
The step-by-step Python tutorials are still being written.
:::

The Python API mirrors the JavaScript one: the same `chart()`, `.flow()`,
`.mark()` builder, the same marks and graphical operators, only spelled with
keyword arguments instead of option objects. So the
[JavaScript tutorials](/js/tutorials/) teach everything you need in the
meantime — Basics first, then Charts or Diagrams in either order. Use the
language toggle at the top to switch back.

Elsewhere in these docs:

- [First Steps](/python/get-started) walks through installing the package and
  building your first chart.
- The [API Reference](/python/api/core/chart) documents every operator and mark.
- The [examples](/python/examples/) show finished specs in Python.
