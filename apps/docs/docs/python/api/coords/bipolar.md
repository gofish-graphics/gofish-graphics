# Coord.bipolar

Bipolar coordinates: the plane described by two foci rather than one center.
Positions bend around both poles, which suits paired or two-source geometry.

::: warning Not in the Python API yet
The Python wrapper exposes `Coord.polar()`, `Coord.clock()`, and `Coord.wavy()`; `Coord.bipolar()` has no
Python factory yet. See the [JavaScript page](/js/api/coords/bipolar) for the
call shape.
:::
